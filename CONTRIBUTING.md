# Contributing

- Protocol changes start in [spec](https://github.com/squaddle-org/spec) — implementation PRs follow a spec release.
- Sign off your commits (DCO): `git commit -s`.
- Conventional Commits (`feat:`, `fix:`, `spec:`), small PRs, tests for reject paths in crypto/membership code.
- No analytics, trackers or Google dependencies in the `foss` builds.
