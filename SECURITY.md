# Security policy

Squaddle is an end-to-end encrypted app. We take reports seriously.

- **Report privately:** GitHub Security Advisories ("Report a vulnerability" on the affected repo) or security@squaddle.org.
- Please don't open public issues for vulnerabilities.
- We aim to acknowledge within 72 hours and coordinate disclosure with you.
- In scope: all public repos and the hosted services (squaddle.org, relay.squaddle.org).
- Particularly interesting: anything that lets the relay or a non-member read content, forge membership/roles,
  bypass invite expiry, or keep access after being removed.
